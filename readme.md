## 📌 Sobre o Projeto

Este projeto é o **website institucional oficial da Agência Prodev**, especializada em **desenvolvimento de software sob medida**, **websites profissionais** e **automações inteligentes com N8N**.

O site foi desenvolvido como uma **Single Page Application (SPA estática)**, com foco em:

- Autoridade digital
- Conversão de leads
- Performance e SEO
- Design moderno e profissional
- Experiência do usuário (UX/UI)

Toda a comunicação foi pensada para transmitir **credibilidade, inovação e clareza técnica**, alinhada ao posicionamento da Agência Prodev no mercado de tecnologia.

## 🚀 Como Executar Localmente

### Pré-requisitos

Nenhum. Projeto 100% estático.

### Opções de execução

Abrir diretamente no navegador:
```bash
index.html
```

Ou utilizando um servidor local:

```bash
# Python
python -m http.server 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```

Acesse no navegador:
```bash
http://localhost:8000
```

## 🚀 Deploy

O projeto está preparado para deploy na **Vercel**, garantindo alta performance e HTTPS automático.

### 🔹 Recursos configurados

- Deploy automático via GitHub
- Domínio personalizado
- Headers otimizados para SEO
- SPA estática
- Sitemap e robots configurados

### 🔹 Processo de deploy

1. Conecte o repositório à Vercel
2. Selecione o framework como **Other**
3. Utilize a raiz do projeto (`/`)
4. Finalize o deploy
