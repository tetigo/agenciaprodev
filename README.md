# 🚀 Agência Prodev - Site Institucional

Landing page profissional da Agência Prodev, focada em conversão e entrega de sites profissionais em 7 dias.

## ✨ Características

- 🎯 **Foco em Conversão**: Design e copy otimizados para gerar leads
- 📱 **100% Responsivo**: Funciona perfeitamente em todos os dispositivos
- ⚡ **Performance**: Carregamento rápido e otimizado
- 🔍 **SEO Otimizado**: Meta tags, Open Graph, Schema.org e sitemap
- 🎨 **Design Moderno**: Interface limpa e profissional

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript vanilla
- SEO completo (Open Graph, Twitter Cards, Schema.org)

## 📁 Estrutura do Projeto

## 🚀 Como Usar

1. Clone o repositório
2. Abra `index.html` no navegador
3. Ou faça deploy em qualquer serviço de hospedagem estática

## 📦 Deploy

### Vercel (Recomendado)sh
vercel### Netlify
Arraste a pasta para o Netlify Drop

### GitHub Pages
1. Vá em Settings > Pages
2. Selecione a branch main
3. Pronto!

## 🔧 Personalização

- **Cores**: Edite as variáveis CSS em `assets/css/styles.css`
- **Conteúdo**: Edite diretamente o `index.html`
- **SEO**: Ajuste as meta tags no `<head>`
